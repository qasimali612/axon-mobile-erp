## Immediate IMEI purchasing result

The application now exposes the actual workflow clearly:

1. Configure the product/variant as **IMEI tracked**.
2. Open **Purchase / receive stock**.
3. Receive against an approved PO or choose **Direct receipt** (PO optional).
4. Add multiple product lines.
5. Use **Record IMEIs** on phone lines; one row is one physical phone and may contain IMEI 1 and IMEI 2.
6. Save/submit/inspect/approve/post.
7. Verify the device in **Inventory → IMEI Registry**.

Drafts, scans, submission, inspection, and approval do not create available stock. Posting atomically creates physical units, identifiers, movements, balances, accounting, and audit records exactly once.
